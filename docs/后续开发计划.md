## 近期建议

卸载清理后续可补充具体软件名称别名、缓存规则及逐项保留原因说明；安装监控归属与构建输出识别仍待开发。原空间追踪和清理方案计划保留如下。

| 顺序 | 功能 | 首版范围 | 验收重点 |
| --- | --- | --- | --- |
| 2 | 磁盘空间变化追踪 | 本地快照、同范围两次对比、增长目录前 20 名 | 记录扫描范围与完整性；无权限或未扫描目录不能算作空间减少；隔离区占用单独解释 |
| 3 | 多套清理方案 | 保存、切换、复制方案，导入导出 | 使用稳定标识；新规则与风险变化需重新确认；不导出凭据或隔离索引 |

失败结果导出可逐步扩展为用户主动导出的诊断包：包含程序和规则版本、错误码及脱敏路径，导出前预览。历史 `xmp` 注册表报错仍需现场证据。

## 后续候选

| 功能 | 建议范围与依赖 |
| --- | --- |
| 统一恢复中心 | 先关联一次操作的日志、隔离项、注册表与任务备份，实现查询、冲突预览及逐项恢复，再考虑批次恢复 |
| 重复文件保留策略 | 在现有“保留最早”和多选基础上，增加保留最新、优先指定目录及策略预览；保留副本仍须执行前复验 |
| 定期扫描与空间提醒 | 复用清理方案，配置周期和空间阈值；首版只扫描提醒，记录触发身份并避开已有任务 |
| 分批展示与性能优化 | 先测首批结果耗时、总耗时、取消响应和内存，再调整并发；扫描中查看、结束后清理 |
| 规则样例与影响预览 | 每条新增规则提供正反样例，比较新旧规则匹配变化，控制重叠和范围扩大 |
| 自动更新后续 | HTTP Range 续传、稍后提醒 / 跳过版本、更新结果记录；续传完成仍验证整个包 |
| 可访问性与语言 | 键盘导航、高 DPI、屏幕阅读器标签；文本资源化后再增加语言 |

## 配套验收

真实 Windows 权限与升级验收应与功能开发并行规划：普通用户、另一管理员凭据、SYSTEM 服务、多用户、服务运行中升级、权限拒绝、文件占用、空间不足和中断恢复。环境、版本、产物哈希及实际结果必须记录，普通单元测试通过不替代这些结果。

当前代码签名状态与其他限制见[当前状态](当前状态.md)。

## 范围约束

文件恢复、软件搬家、桌面整理不在现有产品范围。新功能继续遵守路径护栏、用户可见选择范围、备份与恢复边界；不以增加删除数量作为扩展目标。

已完成的清理详情、勾选记忆、筛选排序、发布验证、CI 与更新后台下载已从待办移除，见[当前状态](当前状态.md)。
