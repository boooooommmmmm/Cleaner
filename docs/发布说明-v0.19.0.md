# CleanSweep v0.19.0

## 新功能

- 发现新版本后先在后台下载并校验，准备好后再询问是否安装。选择稍后可在设置中安装已下载更新，缓存校验通过后可复用。
- 清理结果支持关键字与风险组合筛选，以及组内按大小、名称、风险或扫描顺序排序。
- 显示当前可见项数和大小；隐藏项保留勾选状态，本次清理只处理显示的选中项。

## 修复与改进

- 合并文件关联、App Paths 等共享注册表键的重复扫描结果，保留 COM 等独立视图。
- 注册表目标已不存在时单独统计，并从列表移除，避免重复显示清理失败。
- 注册表失败详情显示视图和备份阶段；有失败或未完成项时，清理摘要使用提示色。
- 修改更新来源时取消旧下载；取消后不会继续进入安装；网络检查失败时保留已下载更新的安装入口。
- 安装确认前核对本地发布信息签名与目标版本，安装进程仍独立复验。
- 清理进行中禁用“忽略”操作，避免后台任务与前台列表修改交错。

## 验证

- 五轮代码审查，确认的 5 项 P2 问题均已修复。
- 审查收尾验证：537 项测试通过（Core 482、App 55），Release 构建无警告、无错误。
- Windows x64 自包含 ZIP，包含 .NET 运行时；发布信息使用现有可信密钥签名。

## 更新说明

旧版本可在设置中检查更新，或下载本页 ZIP。静默下载后确认安装的新流程在升级到 v0.19.0 后生效。

`xmp` 注册表导出失败的现场原因尚未复现，本版不保证消除所有导出失败。真实管理员/SYSTEM 服务更新与断电恢复场景仍待专门验收。
