## 已完成的近期能力

- 清理条目展示依据、影响、恢复方式与执行前核对；支持关键字及风险筛选、组内排序。
- 记住当前用户上次清理勾选；类型或风险变化时不沿用旧选择。隐藏条目不参与当前清理。
- 重复文件支持整行选择、Ctrl / Shift 多选、Ctrl+A 与 Esc，并在执行前核对保留副本。
- 隔离区支持按盘概览、按批次与关键字筛选。
- 程序更新先后台下载、校验，再询问安装；支持进度、取消、重试、完整包复用、重启恢复和页面忙碌时暂缓安装。
- 统一验证脚本与 GitHub Debug / Release CI 已接入；公开验证不读取私钥。

完整功能清单见[项目 README](../README.md)，实现入口见[产品设计](产品设计-Windows系统清理软件.md)。
