# 重复文件整行选择与快捷键

> 历史归档：正文描述记录当时的设计、代码与验证结果，其中的待办、版本和“未修复”不代表当前状态。请从[文档索引](../README.md)查看当前状态与开发计划。

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 单击文件行的路径、时间或空白处 | 选中该行，清除其他行选择 |
| Ctrl + 单击 | 追加选中或取消该行，保留其他选择 |
| Shift + 单击 | 从上次选择的起点连续选择，支持跨重复组和反向选择 |
| Ctrl + Shift + 单击 | 在已有选择上追加连续范围 |
| Ctrl + A | 列表获得焦点时选中所有文件，包含屏幕外的项目 |
| Esc | 列表内清除选择 |
| 上下方向键、Home / End | 使用标准列表键盘导航；Shift 可扩展选择范围 |
| Ctrl + 空格 | 切换当前焦点行的选择 |
| 单击复选框 | 单独切换对应文件的勾选 |
| 单击“打开位置” | 打开所在位置，保持选择 |

行高亮、复选框和顶部已选数量表示同一批待隔离副本。分组标题继续显示，但不参与选择。

## 保留副本与执行限制

允许先全选再调整保留项。只要任意组被全部选中，“移入隔离区”按钮就禁用，已选汇总提示每组至少取消一份。执行方法仍保留原有检查，实际操作前仍需确认并复核拟保留副本的内容。

查找或移入隔离区期间，列表和批量选择按钮禁用。移除已处理的行时保留其他行的选择；重新查找后不会遗留旧行或旧事件订阅。

## 实现与验证

- [DuplicatesPage.xaml](../../src/CleanSweep.App/Views/DuplicatesPage.xaml)：单个分组 ListBox，使用 Extended 选择模式，双向同步 IsSelected；按当前数据行保持原分组顺序。
- [DuplicatesPage.xaml.cs](../../src/CleanSweep.App/Views/DuplicatesPage.xaml.cs)：Esc 清除选择。
- [DuplicatesViewModel.cs](../../src/CleanSweep.App/ViewModels/DuplicatesViewModel.cs)：维护行集合、选择汇总和执行条件。
- [DuplicateSelectionTests.cs](../../tests/CleanSweep.App.Tests/DuplicateSelectionTests.cs)：5 个实际 WPF 页面回归测试。

沿用原页非虚拟化的显示方式，保证屏幕外行的双向选择绑定也同步。若后续启用虚拟化，需要同时补齐独立于行容器的选择同步，不能只打开虚拟化开关。

测试覆盖行点击对应的原生选择路径、复选框同步、打开位置不改变选择、跨组与反向范围选择、Ctrl 切换、Ctrl+Shift 追加、100 行的全选与 Esc 清除、工具栏联动、忙碌时禁用，以及删行/重新查找后的状态。测试在专用 STA 线程调用原生选择分支和路由命令，不向用户桌面注入键鼠事件，不移动真实文件。
