# 清理勾选状态记忆

> 历史归档：正文描述记录当时的设计、代码与验证结果，其中的待办、版本和“未修复”不代表当前状态。请从[文档索引](../README.md)查看当前状态与开发计划。

## 行为

系统清理、应用缓存、残留清理、开发者缓存、注册表清理和隐私清理共用此功能。

- 勾选或取消勾选后自动保存，无需先执行清理；重新扫描、切换页面或重启后，同一条目恢复上次状态。
- 分组复选框、“只选显示的安全项”和“显示项全不选”同样保存。筛选外的条目保持原状态。
- 按当前 Windows 用户、模块 ID 和条目稳定 ID 匹配，文件数量及体积变化不影响恢复；本次未扫描到的条目保留记录。
- 没有记录的新项目使用原默认状态。条目风险级别或操作类型变化时，原记录不用于自动勾选。
- 权限不足的条目保持禁用，不覆盖先前有权限时保存的选择。
- 清理失败、取消后程序自动取消勾选，以及清理成功后从列表移除条目，不改写用户偏好。
- 仍需人工点击清理并确认；记忆不会自动执行清理。

## 存储与界面

使用现有数据目录下 `settings.json` 的 `CleaningSelections` 字段，沿用临时文件加原子替换保存。旧版设置没有此字段时兼容默认行为，不清空其他设置。

页面标题下说明自动记忆行为。写入失败会显示“勾选状态未能保存”，并在后续选择事件中重试。扫描/清理期间禁用批量选择，避免把操作中的临时状态写入偏好。
