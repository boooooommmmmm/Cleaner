## 本轮完成

针对清理报告中重复出现的“键已不存在”和难以定位的备份失败，完成扫描去重、结果分类与错误提示改进。改动已在工作区完成，尚未发布新版本。

### 共享注册表键去重

- 对已知共享路径，按注册表 hive、路径、项目类型和值名合并 32 位与 64 位视图的扫描结果。
- 覆盖文件扩展名、ProgID、打开方式程序、App Paths 和 HKCU Software 下的共享项。
- Classes 下的 CLSID、DirectShow、Interface、Media Type、MediaFoundation 以及未识别路径仍保留各视图；不会把两个独立的 COM 注册项合并。
- 保留首次扫描结果的 ID 和快照，删除前仍需核对目标是否变化。

路径规则依据：[Microsoft：Registry Keys Affected by WOW64](https://learn.microsoft.com/windows/win32/winprog64/shared-registry-keys)。实现针对项目支持的现代 Windows。

### 已不存在的目标单独统计

- 清理前确认注册表键或值已不存在时，显示“目标已不存在，无需清理”，并从结果列表移除。
- 单独计数，不增加删除数，不产生备份，不计入失败，也不重复要求用户清理。
- 操作日志记录 `already-absent`。
- 权限和读取失败仍按失败处理。值的缺失通过枚举值名确认，避免把读取内容失败当成目标不存在。
- 旧扫描结果中即使仍含两个视图的重复项，实际删除和备份也只发生一次。

### 失败提示

- 注册表错误和操作日志显示视图；值操作还显示值名。
- 备份失败时明确显示“备份阶段失败，未执行删除”，保留底层错误。
- 清理仍有失败或未完成项目时，摘要使用提示色；全部处理完成时使用绿色。
