# CleanSweep v0.20.0

## 自动更新改进

- 设置页显示下载进度条、百分比和已下载大小。
- 支持取消程序更新，取消或下载失败后可手动重试；完整且校验通过的包会复用。
- 已下载的更新可在重启后从本地恢复，重新验证签名、版本、大小和 SHA-256 后显示安装入口；关闭启动检查也会恢复本地包。
- 联网检查失败时保留已下载包，可稍后安装。
- 清理、扫描、粉碎、隔离区操作或规则库更新进行时暂缓安装，任务结束后可手动安装；切换页面不会漏掉原页面的任务。
- 安装确认前、用户同意后启动安装器前，都会检查任务状态。
- 设置页可展开查看版本说明。

## 验证

- 557 项测试通过：Core 482、App 75，其中新增 20 项缓存、取消、安装时机和 WPF 页面绑定测试。
- Release 构建通过，0 警告、0 错误；数据集与发布信息使用现有可信密钥验证。
- Windows x64 自包含 ZIP，包含 .NET 运行时。

## 使用说明

旧版本可在设置中检查更新，或下载本页 ZIP。上述改进在升级到 v0.20.0 后生效。

未完成的下载重试时会重新下载，暂不支持断点续传。旧版本下载但尚无缓存索引的包，需要检查更新后通过原有校验流程复用。真实 UAC、管理员 / SYSTEM 服务更新和安装回滚仍需对应环境的端到端验收。
