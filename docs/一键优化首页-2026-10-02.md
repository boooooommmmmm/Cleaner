# 一键优化首页

日期：2026-10-02。v0.22.0 功能说明；发布状态见[当前状态](当前状态.md)。

## 入口与交互

- 侧栏顶部固定“一键优化”，启动后默认显示首页。
- 蓝绿渐变主卡、醒目按钮、执行时旋转的进度环、650 毫秒数字过渡动画；尊重 Windows 的动画开关。
- 主卡直接显示本次范围，下面可分别勾选临时文件、网页缓存、运行日志和可选的内存操作。
- 点击后自动扫描和处理勾选范围；支持停止。停止清理后保留已处理结果，文件可从隔离区恢复。
- 执行期间禁用范围修改、其他页导航及管理员重启；程序更新安装也会等待任务结束。关闭窗口先请求停止，完成后可再次关闭。
- 未完成项目可展开查看具体路径和原因；提供隔离区、内存与进程、开机记录的入口。

## 默认处理范围

| 范围 | 条件 |
| --- | --- |
| 当前用户临时目录 | 位于当前用户 LocalAppData 内，超过 7 天未修改的文件 |
| Windows 网页缓存 | LocalAppData/Microsoft/Windows/INetCache 内超过 7 天未修改的文件 |
| .NET Framework 使用日志 | LocalAppData/Microsoft/CLR_v4.0/UsageLogs 和 CLR_v4.0_32/UsageLogs 内超过 30 天未修改的文件 |

首页采用固定规则 ID 与实际路径双重限制，只接受 Safe、Always、文件集合且无前置动作的规则目标。规则库将年龄门槛调得更严格时，首页遵守更严格的门槛。不会把所有标记 Safe 的规则自动加入首页。

文件逐个移入隔离区，复用路径护栏、扫描后大小/时间变化检查、物理路径检查与白名单。沿用系统清理条目 ID，尊重此前的项目排除。空子目录沿用引擎原有处理，扫描根保留。文件占用是否阻止移动取决于共享模式，不能承诺任何使用中的文件都绝不会移动。

注册表、服务、启动项、回收站、组件存储、驱动、整目录残留以及百度网盘临时文件不参加首页一键处理。超过一定天数也不等于绝对无用，因此默认保持可恢复；界面不承诺零风险。

## 数字的含义

| 展示项 | 数据来源与边界 |
| --- | --- |
| 已整理文件数 | 清理引擎成功移入隔离区的文件数 |
| 已整理到隔离区 | QuarantinedBytes，可恢复；并不代表已释放磁盘空间 |
| 本次直接释放磁盘空间 | FreedBytes；当前首页只隔离文件，因此通常为 0 B |
| 可用内存变化 | 处理后减处理前的系统可用内存；允许负数，缺失显示破折号，其他程序活动也会影响读数 |
| 最近一次开机耗时 | Windows 启动性能事件日志最新记录；没有记录则显示破折号 |

首页不自动修改启动项，因此不展示没有测量依据的“开机提速百分比”。查看启动记录与调整启动项仍从开机加速页进入。

内存选项“释放低优先级待机缓存”默认关闭，需要现有管理员权限，不自动提权，不结束进程，也不清空进程工作集。调用失败时显示原因，已完成的文件结果保留。缓存可能重新建立，不保证可用内存增加或程序提速。仅采样时跳过 WMI 待机缓存查询，直接读取所需的系统内存信息。

## 同步修复

CleanEngine 在执行条目前复查项目、规则和目标路径白名单，并且不会为已经排除的条目执行前置动作。修复了[百度网盘规则审查](百度网盘规则审查-2026-10-02.md)中的 P3。该审查的 P2 同名普通文件问题也在[发布前审查](发布前审查-v0.22.0.md)中修复。首页有独立的目录存在性检查，百度规则不在首页范围内。

发布前还补充独立的内存成功状态：跳过或失败时，顶部显示“处理结束，内存操作未完成”，保留已完成文件的统计。
