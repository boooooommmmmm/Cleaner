# v0.22.0 发布前审查

日期：2026-10-02。范围：v0.21.0 发布后的一键优化首页、百度网盘规则、白名单修复及发布集成。按用户要求完成一轮代码、复现与回归审查。

## 结论

确认并修复 2 项问题，修复后的本轮范围未发现未处理的发布阻塞项。不把测试通过解释为不存在任何缺陷；真实 UAC/SYSTEM、安装回滚和断电恢复仍为专门验收范围。

### P2：目录位置的同名普通文件绕过模式限制（已修复）

`RuleScanner` 原来的单文件分支只检查属性和年龄，未应用 `pattern` / `exclude`。当 Documents/BaiduNetdiskTmp 为普通文件时，百度网盘规则会把它作为候选。

修复：单文件分支使用相同的模式/排除规则；百度规则增加目录检测，并使用会执行检测的 `when=installed`。这里的检测条件仅为目录存在，不要求软件登记为已安装。兼容旧客户端仅接收规则更新的场景。

验证：同名普通文件不再列出、原文件保留；正常旧 `.tmp.node` 仍列出；显式单文件（如 MEMORY.DMP）和分号分隔模式保持可用，排除模式生效。额外使用已发布 v0.21.0 的 Core DLL 加载新规则，普通文件 0 候选、正常目录 1 候选，均通过。

### P3：内存操作跳过或失败，主标题仍显示完成（已修复）

勾选内存选项后，权限不足等情况虽然有详细说明，但顶部仍显示“整理完成”，容易被理解为所有请求均已成功。

修复：执行结果携带独立的内存成功状态，未完成时顶部显示“处理结束，内存操作未完成”；已完成的文件统计保留，取消状态仍优先展示。成功/失败分支新增回归。
