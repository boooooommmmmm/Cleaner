# CleanSweep v0.21.0

## 新增

- 清理结果按占用、权限、扫描后变化、备份失败等原因分类，提供处理建议与 JSON 导出；取消后保留已取得的结果。
- 重新扫描未完成项目，刷新内容后取消全部勾选，避免直接重试过期的扫描结果。
- 新增“僵尸目录”：识别当前用户 AppData 中有卸载记录的已知缓存、日志与真正为空的应用目录。清理前复核安装状态和范围，文件移入隔离区。
- 卸载完成后按应用预览缓存和空目录，支持再次预览、整批卸载监听事件和切回全部扫描。定向预览每次都需重新勾选。

## 修复与维护

- 卸载程序未结束时不提示“已卸载”；刷新列表后保留实际卸载结果。
- 批量卸载提醒覆盖整批应用；忙碌状态下阻止切换预览范围。
- 整理当前文档、开发计划和发布流程，历史审查保留在归档中。

## 使用边界

- 僵尸目录依赖卸载记录和已知规则，没有依据的目录保留；不扫描 Program Files、ProgramData 或个人文档目录。
- 非空应用根目录、配置、存档等不作为本功能的整体清理目标。用户主动放入缓存目录的文件仍需自行核对。
- 移入隔离区后通常不会立即释放磁盘空间，到期或永久删除后才释放。
- 导出报告包含本机路径；提权服务文件失败明细仍有现有协议数量限制。
- 真实 UAC、SYSTEM 服务升级、安装回滚和断电恢复仍需专门环境验收。

## 更新方式

现有客户端检查到新版本后，会先后台下载并校验，再询问是否安装。也可从本版本附件下载 win-x64 自包含 ZIP。
