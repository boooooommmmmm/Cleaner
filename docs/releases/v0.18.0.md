# CleanSweep v0.18.0

## 新增与交互改进

- 清理页面自动记住勾选与取消勾选的项目，重新扫描及重启后恢复。支持分组与批量选择；新项目、风险或操作类型变化的项目使用默认状态。
- 重复文件支持整行选择、Ctrl 多选、Shift 连选、Ctrl+Shift 追加范围、Ctrl+A 全选、Esc 清除及标准键盘导航；支持跨重复组选择，行高亮与复选框同步。
- 重复文件某组全部选中时显示保留副本提示并禁用隔离操作，调整选择后恢复可用。

## 修复

- 修复磁盘健康页分析、优化、重新修剪、碎片整理和计划检查磁盘按钮点击无响应的问题。
- 清理执行范围与当前筛选保持一致，隐藏的勾选项不参与本次清理。
- 隔离区“删除过期项”遵循当前磁盘、批次和搜索筛选，并使用权限回退；单项恢复与删除正确设置忙碌状态。
- 修复健康内存诊断误报异常，以及目标风扇转速被当成实测值显示的问题。
- 提权服务保留文件占用的真实跳过原因；修正隔离保留期、容量淘汰和备份恢复说明。

## 开发与发布验证

- 新增统一验证脚本和 Windows Debug / Release CI。
- 增加界面回归测试，覆盖勾选记忆、磁盘按钮参数和重复文件选择。
- 发布流程检查源码提交状态、程序版本，以及签名发布元数据与安装包的名称、长度和 SHA-256。

## 安装与升级

下载 `CleanSweep-win-x64-0.18.0.zip`，解压后运行 `CleanSweep.exe`。程序为 Windows x64 自包含版本，无需另装 .NET。

已有版本可通过程序内更新检查获取新版本。实际管理员／SYSTEM 服务与完整升级回滚场景仍需在 Windows 虚拟机中进一步验收。
