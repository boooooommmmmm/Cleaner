# CleanSweep v0.22.0

## 一键优化首页

- 侧栏顶部固定入口，打开程序默认进入首页。
- 默认整理当前用户 7 天以上的临时文件、Windows 网页缓存，以及 30 天以上的 .NET 使用日志；文件逐个移入隔离区，可恢复。
- 蓝绿渐变主卡、执行进度环与数字动画，分别显示整理文件数、隔离体积、实际直接释放量、可用内存变化和最近开机耗时。
- 可选释放低优先级待机缓存，默认关闭，需管理员权限；跳过或失败会明确提示。内存变化可能受其他程序活动影响，不保证提速。
- 可停止任务并保留已完成结果；处理期间防止更新安装、管理员重启及其他页面操作中断任务。

隔离文件仍占用磁盘空间，到期或永久删除后才释放。首页不自动改动启动项，不估算开机提速百分比。

## 百度网盘临时文件

- “应用缓存 → 百度网盘”支持默认 Documents/BaiduNetdiskTmp 顶层超过 7 天未修改的 `*.tmp.node`。
- 需用户确认，首次默认不选；保留其他文件、子目录和目录本身，建议退出网盘并确认任务结束后再清理。
- 目录存在性检测兼容旧客户端的规则更新，同名普通文件不会作为候选。该规则不参加首页一键优化。

## 修复

- 单文件扫描也遵守文件模式和排除模式，避免目录位置被同名文件替代后扩大清理范围。
- 执行前复查规则、项目和路径白名单，排除项的前置动作不再执行。
- 请求的内存操作未完成时，首页不再显示无条件完成标题。

规则库升级到版本 6，共 75 条规则。程序更新继续采用后台下载、签名校验后询问是否安装的流程。
