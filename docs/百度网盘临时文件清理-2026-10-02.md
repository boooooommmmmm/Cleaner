# 百度网盘临时文件清理

依据用户截图中的 `Documents\BaiduNetdiskTmp\*.tmp.node` 添加规则，随 v0.22.0 提供。发布状态见[当前状态](当前状态.md)。

## 使用范围

入口为“应用缓存 → 百度网盘”。新增规则 `baidu.netdisk-temp-nodes`：

| 条件 | 设置 |
| --- | --- |
| 路径 | `%UserProfile%\Documents\BaiduNetdiskTmp` |
| 文件模式 | `*.tmp.node` |
| 递归 | 否，只扫描顶层文件 |
| 文件年龄 | 最后修改时间早于 7 天前 |
| 风险 | 建议确认，首次不默认勾选 |
| 安装检测 | 不要求应用仍安装；指定目录存在且有匹配文件时展示 |
| 执行 | 逐文件移入隔离区；保留目录本身和其他文件 |

这是根据截图路径和文件名提供的临时文件候选规则，没有将该类文件的用途和生命周期视为已经通过官方资料确认。7 天阈值用于减少近期文件命中，不证明文件已经不再需要。条目提示用户退出网盘、确认没有进行中的任务后再选择；清理可能需要网盘重新生成或下载组件。

不匹配普通 `.node`、`.tmp`、下载中间文件、普通文档、子目录，以及其他位置的同名文件；不删除整个 Documents 或 BaiduNetdiskTmp。已占用、扫描后变化、白名单、重解析点和云端占位文件沿用现有引擎保护。

首版与截图一致，仅覆盖默认用户目录下的 Documents 路径；不新增重定向文档目录或自定义网盘临时路径探测。
